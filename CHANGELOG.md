# Changelog

All notable changes to Hisaab Kitaab are documented here.

## [6.0] — 2026-11-11
- Fixed Delete for good: entries are now deleted through an in-app confirmation dialog (Android WebView silently blocked the old browser confirmation). A native dialog handler was also added as a safety net.
- Fixed a hidden bug where Delete All data could be restored from the backup mirror.
- Dashboard redesigned to a premium, professional layout: personal greeting, dark-green balance panel with month-health status, underline month tabs, unified money overview, monthly snapshot metrics and clean recent activity with icon Edit/Delete.

## [5.0] — 2026-11-11
- Real-app back behaviour: Back from any section returns straight to the Dashboard, the editor returns to the section it was opened from, and Back on Home exits the app.
- Settings upgraded: date format, week-start day and privacy mode (hide amounts).

## [4.0] — 2026-11-11
- Header finalised: logo and app name on the left, bell and menu on the right, drawer opens from the right.
- Records grouped by date in Transactions and Monthly Records, with labelled Edit/Delete on every entry.
- Back arrows removed from all pages; dark-green header and month tabs restored.

## [3.0] — 2026-11-11
- Monthly Records section with clean per-month tables.
- Profile photo support.
- Real PDF and Excel exports added (plus CSV and JSON backup).
- Data mirrored into native storage so records cannot be lost.

## [2.0] — 2026-11-11
- Renamed to **Hisaab Kitaab** with a full professional redesign in English.
- First-launch onboarding details page (shown once, editable later from Profile).
- Full-page Add Entry with a success popup; tappable Income and Savings cards.

## [1.0] — 2026-11-11
- First release as **GharHisab Pro**: expense/income/saving/deduction entries, month tabs, calendar, table view, charts, month-end summary notification, profile, settings and JSON/CSV backup.
